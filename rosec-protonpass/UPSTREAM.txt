Distribution
============

Release downloads pair rosec-provider-protonpass-VERSION.wasm.tar.gz with
rosec-provider-protonpass-VERSION.source.tar.gz and checksums for both.
The source archive contains the committed tree, lockfiles, build scripts,
vendored dependencies and offline rebuild instructions. The binary archive
includes the GPL text, provenance and dependency notices. Preserve those
notices alongside the host's MIT licence.

From a clean committed checkout:
  python3 contrib/package-protonpass.py --version VERSION --output dist/protonpass

The release workflow signs the production WASM and policy sidecar. Never
ship the test-http feature. Source builds for rosec-git use --notices-only
to collect dependency notices without producing a release source archive.
The Rust compiler, WASI standard library and system tools are prerequisites.
